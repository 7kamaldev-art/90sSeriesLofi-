# 🎵 90s Lofi Music Player

Ek beautiful, **ad-free** music player website jaha aap gana suno aur playlist share kar sakte ho!

## ✨ Features

✅ **Ad-Free Music Streaming** - Kisi bhi ads ke bina gana suno  
✅ **Beautiful UI** - 90s aesthetic ke saath modern design  
✅ **Playlist Support** - Apne playlist ke songs ko share karo  
✅ **Full Player Controls** - Play, Pause, Next, Previous, Volume Control  
✅ **Dark/Light Theme** - Teri pasand ke hisaab se theme choose karo  
✅ **Responsive Design** - Mobile aur desktop dono par perfectly kaam karta hai  
✅ **Keyboard Shortcuts** - Space bar se play/pause, Arrow keys se next/previous  
✅ **Share Link** - Apna playlist link copy karke dost ko share karo  

## 🚀 How to Use

1. **Website khol** - `index.html` ko browser mein open karo
2. **Playlist link daal** - YouTube ya Spotify playlist ka link paste karo (ya sample use karo)
3. **Load karo** - "Load" button dabao
4. **Enjoy karo** - Gana suno aur enjoy karo! 🎧

## 🎨 Customization

### Colors badalna ho toh:
`style.css` mein ye values change karo:
```css
#ff6b9d  /* Pink color */
#9c8cff  /* Purple color */
```

### Apne songs add karna ho toh:
`script.js` mein `loadSamplePlaylist()` function ko modify karo:
```javascript
playlist = [
    { 
        title: 'Song Name', 
        artist: 'Artist Name', 
        url: 'song-link.mp3',
        duration: 200 
    },
    // More songs...
];
```
